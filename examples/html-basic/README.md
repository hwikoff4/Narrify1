# Narrify - HTML Basic Example

A standalone HTML page using Narrify via a script tag. No build step required.

## Usage

1. Open `index.html` in your browser
2. Replace `YOUR_API_KEY` with your actual Narrify API key
3. Click "Start Tour" to see the demo tour

## What's Included

- Script tag loading from jsdelivr CDN
- A 3-step tour highlighting hero, navigation, and features
- Inline tour definition (no server needed)
