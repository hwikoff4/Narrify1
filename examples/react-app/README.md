# Narrify - React Example

A Vite + React + TypeScript app using `@narrify/react`.

## Setup

```bash
npm install
npm run dev
```

## What's Included

- `NarrifyProvider` wrapping the app
- `useNarrify` hook for tour controls
- A 3-step demo tour
- Start/stop tour button

## Notes

- Replace `YOUR_API_KEY` in `src/App.tsx` with your actual Narrify API key
- Requires `html2canvas` as a peer dependency (already in package.json)
